# 🍔  Responsive Food Landing Page

A modern and responsive **Food Landing Page** built using **React, Tailwind CSS, and Framer Motion**.
This project showcases a clean UI with smooth animations, interactive components, and mobile-friendly design.

## ✨ Features

* ⚡ Fully responsive design (Mobile + Tablet + Desktop)
* 🎯 Interactive Hero section with dynamic image change
* 🖼️ Scrollable food slider
* 🛒 Add to Cart functionality
* 🎬 Smooth animations using Framer Motion
* 📌 Single-page navigation (scroll-based)
* 🔗 Quick links in Navbar & Footer
* 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

* ⚛️ React (Vite)
* 🎨 Tailwind CSS
* 🎬 Framer Motion
* 🌐 HTML5 + CSS3 + JavaScript

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/foodie-landing-page.git
```

Go to project folder:

```bash
cd foodie-landing-page
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

---

## 🎯 Usage

* Click on **Navbar or Footer links** to smoothly scroll to sections
* Select food from slider → updates hero image
* Click **Add to Cart** → cart counter increases
